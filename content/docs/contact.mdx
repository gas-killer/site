Questions about an integration, a task that will not settle, or access to the
public testnet — here is where each goes.

| Channel | Use it for |
| --- | --- |
| [contact@gaskiller.xyz](mailto:contact@gaskiller.xyz) | Email — API key requests, partnerships, anything that is not a quick question. |
| [Telegram group](https://t.me/gaskillerfriends) | Chat with the team and other integrators, and keep up with updates. |
| [Support channel](https://t.me/gaskillerfriends/1) | Issues and technical assistance. |
| [@gaskiller_ on X](https://x.com/gaskiller_) | Announcements and release notes. |

When you report a problem with a task, include the `task_id`, the target
contract address, and the error `code` from the response envelope — that is
usually enough to identify the cause without a round trip. The
[Solidity Reference](/docs/solidity/reference) lists the revert selectors a
settlement can fail with, and
[Configuration](/docs/solidity/configuration) covers the addresses a target must
be wired to, which is the most common source of failures.
