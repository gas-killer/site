          Returns the full state of a single task. Poll this endpoint until
          `status` is `ready`, at which point `payload` holds a ready-to-sign
          transaction request. This is the authoritative freshness check: for a
          `ready` task the router re-validates the payload against current chain
          state, so a stale payload returns `409 PAYLOAD_EXPIRED` (re-request
          the task) rather than calldata that would revert on submission. A task
          is visible only to the API key that created it.
