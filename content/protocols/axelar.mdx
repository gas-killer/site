Gas Killer could cut the gas cost of the Axelar Gateway's `execute` by **22–37%**, about 92,000–107,000 gas on each call. Each `execute` approves a batch of cross-chain messages after checking validator signatures. We measured this on real Ethereum mainnet calls in October 2026. The Gateway received 137 `execute` calls in one day.

## Where the saving comes from

The saving comes from the validator-signature check. The Gateway doesn't run it itself: it calls a separate auth contract ([`0xe3b83f79…`](https://etherscan.io/address/0xe3b83f79fbf01b25659f8a814945ab82186a8ad0)), which spends about 120,000 gas, nearly all of it on `ecrecover`.

- **What gets cheaper:** the signature check runs off-chain. On-chain, only the approved messages and the events are applied.
- **What stays the same:** which messages are approved, and every rule the auth contract enforces.
- **What integration involves:** both the Gateway and the auth contract would use the Gas Killer SDK, settling together as a nested settlement. Without the auth contract, the Gateway alone saves nothing.

## How we measured

We replayed each transaction as Gas Killer would settle it and compared the gas against what it actually cost.

- **Real data:** real mainnet `execute` calls from October 2026, replayed at the block they ran in.
- **Includes all costs:** the gas saved is net of the signature check and every storage write.
- **Nested settlement:** measured with the auth contract integrated too. The analyzer link below includes it.
- **An estimate:** Axelar has not integrated Gas Killer, so the numbers estimate a future integration.
